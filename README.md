# 🤖 ربات ساز تلگرام با هوش مصنوعی

این یک ربات تلگرام پیشرفته است که به شما امکان می‌دهد ربات‌های هوش مصنوعی خود را بسازید و مدیریت کنید.

## ✨ قابلیت‌ها

- 🤖 ساخت ربات‌های هوش مصنوعی شخصی
- 💬 چت هوشمند با استفاده از Groq AI
- 📷 تولید تصویر با هوش مصنوعی
- 💰 سیستم مدیریت اعتبار و شارژ
- 👨‍💼 پنل مدیریت قدرتمند
- 💳 سیستم پرداخت با رسید
- 📊 آمارگیری کامل
- 📢 ارسال پیام همگانی

---

## 🚀 راهنمای نصب در Replit.com

### مرحله 1: ایجاد پروژه جدید

1. به [Replit.com](https://replit.com) بروید و وارد شوید
2. روی **+ Create Repl** کلیک کنید
3. **Template**: Python را انتخاب کنید
4. **Title**: نام دلخواه (مثلاً "AI-Bot-Maker") را وارد کنید
5. روی **Create Repl** کلیک کنید

### مرحله 2: آپلود فایل‌ها

1. تمام فایل‌های این پوشه را به Replit آپلود کنید:
   - `server.py`
   - `requirements.txt`
   - `.env.example`

2. فایل `.env.example` را به `.env` تغییر نام دهید

### مرحله 3: تنظیم MongoDB

**گزینه 1: MongoDB Atlas (رایگان - پیشنهادی)**

1. به [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) بروید
2. یک اکانت رایگان بسازید
3. یک Cluster رایگان ایجاد کنید
4. در بخش **Database Access**، یک کاربر بسازید
5. در بخش **Network Access**، IP `0.0.0.0/0` را اضافه کنید
6. روی **Connect** کلیک کنید و **Connect your application** را انتخاب کنید
7. Connection String را کپی کنید

**گزینه 2: استفاده از MongoDB محلی Replit**

برای استفاده آسان‌تر، می‌توانید از پکیج `pymongo` استفاده کنید و در Repl یک MongoDB محلی راه‌اندازی کنید.

### مرحله 4: تنظیم متغیرهای محیطی

فایل `.env` را باز کنید و موارد زیر را تنظیم کنید:

```env
# MongoDB
MONGO_URL="mongodb+srv://username:password@cluster.mongodb.net/"
DB_NAME="bot_factory_db"

# CORS
CORS_ORIGINS="*"

# Groq API (برای چت AI)
GROQ_API_KEY="gsk_your_groq_api_key_here"

# Main Bot Token (از BotFather دریافت کنید)
MAIN_BOT_TOKEN="your_main_bot_token_here"

# Admin User ID (شناسه تلگرام خودتان)
ADMIN_USER_ID="your_telegram_user_id"
```

### مرحله 5: دریافت توکن‌های مورد نیاز

#### 🤖 دریافت Bot Token از BotFather:

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید
2. دستور `/newbot` را ارسال کنید
3. نام و نام کاربری برای ربات انتخاب کنید
4. توکن دریافتی را در `MAIN_BOT_TOKEN` قرار دهید

#### 🔑 دریافت Groq API Key (رایگان):

1. به [Groq Console](https://console.groq.com) بروید
2. ثبت نام کنید
3. از بخش API Keys یک کلید جدید بسازید
4. کلید را در `GROQ_API_KEY` قرار دهید

#### 👤 پیدا کردن User ID خودتان:

1. به [@userinfobot](https://t.me/userinfobot) پیام دهید
2. عدد `Id` را در `ADMIN_USER_ID` قرار دهید

### مرحله 6: نصب کتابخانه‌ها

در Terminal پایین Replit دستور زیر را اجرا کنید:

```bash
pip install -r requirements.txt
```

### مرحله 7: اجرای ربات

#### روش 1: استفاده از فایل main.py

یک فایل `main.py` ایجاد کنید با محتوای زیر:

```python
import uvicorn
import os

if __name__ == "__main__":
    port = int(os.environ.get("PORT", 8000))
    uvicorn.run("server:app", host="0.0.0.0", port=port, reload=False)
```

سپس روی **Run** کلیک کنید.

#### روش 2: اجرای مستقیم

در Terminal دستور زیر را وارد کنید:

```bash
python -m uvicorn server:app --host 0.0.0.0 --port 8000
```

### مرحله 8: نگه داشتن ربات آنلاین (Always On)

برای نگه داشتن ربات همیشه روشن:

**گزینه 1: استفاده از UptimeRobot (رایگان)**

1. به [UptimeRobot](https://uptimerobot.com) بروید
2. یک Monitor جدید بسازید
3. URL ربات Replit خود را وارد کنید
4. هر 5 دقیقه یکبار بررسی کند

**گزینه 2: Replit Always On (پولی)**

در تنظیمات Repl گزینه **Always On** را فعال کنید.

## 🎯 نحوه استفاده

### برای ادمین (شما):

1. ربات اصلی را در تلگرام استارت کنید `/start`
2. روی "🔑 مدیریت API KEY" کلیک کنید و یک API KEY بسازید
3. روی "🤖 ساخت ربات" کلیک کنید
4. اطلاعات ربات جدید را وارد کنید:
   - نام ربات
   - آیدی کانال (مثل @yourchannel)
   - توکن ربات (از BotFather)
5. ربات شما آماده است!

### برای کاربران ربات‌های شما:

1. ربات شما را استارت می‌کنند
2. در کانال شما عضو می‌شوند
3. شارژ حساب می‌کنند
4. می‌توانند:
   - با هوش مصنوعی چت کنند
   - تصویر تولید کنند
   - موجودی خود را مدیریت کنند
